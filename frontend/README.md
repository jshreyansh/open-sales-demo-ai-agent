# frontend

The frontend for **Open Sales Demo AI Agent** — part of the `open-sales-demo-ai-agent`
monorepo, sibling to `../backend`.

This is the **React Product Replica + Presentation Shell**: a fake-but-real-looking
copy of the product, plus the wrapper the agent presents it inside of during a
sales call. It never talks to a real LLM or does any "thinking" — it exposes
actions and reports state; `../backend` decides what to say and what to click.

For the full concept and system-level architecture, see the root
[`globalplan.md`](../globalplan.md). This repo's own north star and near-term
plan live in [`VISION.md`](./VISION.md) and [`ARCHITECTURE.md`](./ARCHITECTURE.md).
